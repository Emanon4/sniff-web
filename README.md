# 嗅探 Sniff · 网页发布

这是 [Meme](https://github.com/Emanon4/Meme) 母项目「调研嗅探据点」板块的应用网站。Meme 研究内容发现、创作与复盘的方法；Sniff 将选题调研方法用于小红书和抖音的评论现场。

- 母项目与总索引：[Emanon4/Meme](https://github.com/Emanon4/Meme)（私有，需访问权限）。
- 网站维护源码：[Emanon4/Sniff](https://github.com/Emanon4/Sniff)（私有）；本机维护源在 Meme 内的 `调研嗅探据点/网站/`。
- 当前仓库：[Emanon4/sniff-web](https://github.com/Emanon4/sniff-web)，仅保存公开前端构建产物与连接配置，不保存后端、真实采集数据、客户资料或密钥。

网页由 Sniff 的构建和发布脚本生成；本说明的维护源为网站的 `public/README.md`，随构建一同发布。源码修改在 Meme 中进行，不直接维护打包后的 JavaScript 或 CSS。
